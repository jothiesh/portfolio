01 / Flagship · Real-time IoT

GPS Fleet Management

I built a fleet tracking platform that turns GPS device messages into live vehicle positions on a web dashboard.

  • Spring Boot
  • MQTT
  • Netty
  • Kafka
  • MySQL
  • AWS

JMeter load test 20,000 concurrent GPS devices

Telemetry path

  1. 01 / SENDGPS devices
  2. 02 / INGESTMQTT + Netty
  3. 03 / STREAMKafka
  4. 04 / DISPLAYWebSocket dashboard
Read the fleet case study
Problem
Collect frequent location updates from GPS hardware and make them visible to fleet operators in real time.
My contribution
Built device ingestion with MQTT and Netty, streamed events through Kafka, and delivered live updates via WebSockets. Partitioned MySQL data and deployed Docker containers on AWS.
Validation
Load-tested 20,000 concurrent GPS devices using JMeter.

Offline Speed Limiter

An Android app that works without a network connection and communicates with vehicle speed-limiting hardware.

  • Kotlin
  • Jetpack Compose
  • OpenStreetMap
  • UART

Problem
Keep road context available where mobile connectivity is unreliable.
My contribution
Built the Kotlin app and an offline OpenStreetMap engine that considers elevation and road context. Integrated the app with speed-limiting hardware over UART.
Capability

03 / Backend + mobile

Geofence Platform

A Spring Boot backend and Android app for drawing geofences and transferring them to nearby hardware over Bluetooth.

  • Spring Boot
  • JWT
  • Room
  • BLE
  • OSMDroid
Read the geofence case study
Problem
Let field users define areas and transfer them to devices even when offline.
My contribution
Built authentication endpoints with Spring Boot, offline PIN access and Room storage on Android, and chunked transfers over Bluetooth Low Energy.
Capability
Users can choose from six polygon drawing modes and send geofences to a nearby device.
